# 設備請款助手 Pro v15.5

## 平常怎麼用

1. 開啟「案件工作區」，選取「POS設備即時庫存.xlsx」，指定 Excel 起始列與結束列（包含起訖列）。按「套用範圍」顯示該範圍的新增、重複及需決定筆數，再按「確認匯入」。
2. 依報價單號、公司或 SHOP ID 搜尋，勾選需要的案件。進入「查看」可複製拍檔請款描述，或分別複製華茂與拍檔的 Email 及 LINE 文字。
3. 開啟案件，在「廠商銷貨單與發票」選擇華茂或拍檔與文件類型。核對預覽後確認關聯。發票可帶入「請款前整理」，也可手動輸入。核對金額與設備後，勾選「已核對發票、金額與設備」並儲存。
4. 在內部系統建立請款，再回同一案件填寫實際請款單號與日期。華茂「已請款」及「已撥款」各自選擇。
5. 依用途匯出勾選案件。「拍檔請款彙整」包含待補件與已核對案件。「僅匯出已核對的拍檔請款」適用於正式填單。SAP 準備表供人員 Key-in。
6. 勾選案件後，在「勾選案件的廠商下單文字」選擇 LINE、Email 主旨、Email 內文或全部內容。每個廠商各有預覽及一鍵複製，翻頁時仍可一次複製該廠商全部內容。
7. 離開前下載案件工作檔 JSON，隔天由「載入工作檔」繼續。工作檔包含目前資料及來源記錄，請存到公司內部受控位置。原始 PDF 及 Excel 請另外保管。

### 廠商文件匯入與 Excel

- 四個匯入欄位支援樣本所示廠商版型的文字型 PDF。工具讀取文件抬頭及類型，核對案件設備與供應商。預覽顯示銷貨／出貨及發票號碼、日期、未稅／稅額／含稅、原文件有提供的收件資訊、品項和單價。
- 可依華茂銷貨單的收件公司、發票號碼，或拍檔出貨單號、廠商訂單號與案件已有文件核對。請拿原件確認屬於目前案件，再按「確認關聯」。同一文件單號重複匯入時，使用已保存項目的「替換這份文件」。
- 移除或替換文件參考時，既有已儲存的發票與請款回填分別管理。已存發票有金額或日期差異時，先用原有發票表單核對。
- 已確認文件會在相應匯出的「廠商文件」與「廠商品項」補充頁顯示。主表沿用發票核對與分攤規則。逐項含稅金額以文件提供為準，缺少時留空。多項設備的採購單價核對由原有分攤流程處理。
- PDF 解析在瀏覽器完成。案件工作檔 JSON 保存文件名稱、結構化資料與來源欄位，原始 PDF 請留在內部。掃描件可換用原始電子 PDF，或以原有手動發票表單補登。

### 產生內部系統報價單 PDF

1. 開啟案件，確認品項與數量。若有缺價或配對不明，在「逐項銷售單價」填寫並儲存。
2. 核對客戶名稱、報價單號、公司及報價日期，再依需要填入統編、報價窗口、聯絡方式、地址、期限與備註。
3. 按「產生 PDF 預覽」，核對後下載。價格依序使用本案已儲存的逐項單價、可唯一配對的 SAP 歷史單價或報價匯入值。僅有一種完整稅別時會列該稅別合計。兩種稅別金額都完整時，稅額依含稅與未稅合計差額列示。
4. 隨附字型支援可選取的繁中 PDF。檔案約 7 MB。如遇字型不支援的字元，畫面會標出字元以便更正。原始掃描或用印 PDF 可作為附件參考，報價內容以人工確認的資料為準。更新或關閉表單會清除當次預覽。

### 補件與例外

- 可補匯入新版 POS。相同資料不重複新增，變更的資料可更新原案件或另開批次。設備變更後請重新核對發票。
- 案件工作區可補匯入「內部系統報價單.xlsx」、「SAP資料庫」Excel，或在開啟案件後選擇供應商並匯入「請款單匯出.xlsx」。預覽可翻頁，跨頁勾選會在套用時一併納入。銷貨單與掃描報價可在案件詳情加入來源參考並人工補欄。
- Excel 欄位接受原生 XLSX 及相容的舊 XLS。選錯類型、缺少必要的資料欄位或工作表時，畫面會說明原因。廠商下單訊息與華茂查詢結果可翻頁，查詢匯出包含完整結果。
- 同案有多張發票時，逐張選擇對應設備。若相同設備欄分批出貨，可在 POS 補匯入時另開批次。跨案共用發票請填各案分配金額，加總須與原票一致。
- 拍檔供應商代碼可填入已確認值。未填時 SAP 對應欄位留空，待確認頁會列出。庫存有發票紙捲時保留各欄，依原 VK 售價、報價確定的單價，或逐項人工補錄贈品及付費售價。
- SAP 匯出按原 VK 欄序整理勾選案件，保留對應既有單號及歷史文字。產出為 Key-in 用資料副本，工作簿的其他分頁、原巨集及公式不會套用到新檔。若原設備數量或資料來源衝突，請核對「待確認」。

### 使用環境

Excel 操作可從本機打開此網頁。大量檔案可透過套件的本機 HTTP 啟動方式或已部署的 HTTPS 網站使用背景解析。直接開啟本機檔案時，解析在頁面執行，瀏覽器也可能限制 PDF 或剪貼簿功能。

### 核對重複列與調整表格

- 「需決定」會列出比對來源，也會顯示相同欄位和不同欄位的舊值與新值。來源可能是工作區的相符案件，或本次範圍內前一筆相符資料。
- 維持「暫不匯入」的列會略過。確認是另一批設備時，可選「新增為另一批次」。已有對應案件時，也可以指定要更新的原列。
- 案件列表及華茂查詢結果可拖拉滑桿調整表格寬度與顯示高度上限。手機上可左右滑動表格查看其餘欄位。

### 本機使用及 GitHub Pages 更新

- 解開發布 ZIP，保留原資料夾層級。本機可開啟 `index.html`。
- 發布時，在 GitHub 的 **Settings → Pages** 確認來源，將解壓後的全部檔案放到該發布資料夾，同次提交。保留 `index.html`、`.nojekyll`、`vendor/` 和 `docs/` 的相對位置。
- 等待 **Actions** 顯示部署成功，重新整理確認頁首為 **v15.5**。營運 Excel、報價及案件工作檔請留在公司內部。
