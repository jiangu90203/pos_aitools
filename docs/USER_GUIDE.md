# 設備請款助手 Pro v15.23

## 平常怎麼用

1. 按「文件匯入」。可以一起拖入一份 `POS設備即時庫存.xlsx` 和多份華茂、拍檔銷貨單／出貨單、電子發票，也可以先選 PDF 再補 POS。
2. 混合匯入會檢查整份 POS 表，只建立有可靠附件對應的新案件，並更新檔內已匯入的來源列。單獨匯入 POS 時，先輸入起訖列再按「匯入所選列」，畫面會回報新增、更新及略過筆數。
3. 按「下載本批歸檔 ZIP」，取得分案的原始 PDF、配對紀錄及請款 Excel。無法確定案件的 PDF 放入「待核對」。補匯入 POS 或配對所需 PDF 時，工具會重試同一頁面中尚未配對的 PDF。
4. 搜尋或篩選案件，按「查看」開啟右側詳情。單一案件、發票欄位及金額完整時，工具會自動準備請款資料。內部請款完成後回到同一案件填入實際請款單號與日期。
5. 勾選案件後用下方工具列匯出拍檔請款彙整、已核對的拍檔請款、SAP Key-in 準備表或華茂對帳。按「廠商下單」可依廠商預覽與一鍵複製 Email 或 LINE。畫面會顯示預設 To 與 CC。按「使用 Gmail 撰寫」後，在 Gmail 內核對信件、帳號及收件資訊，再加入附件或自行寄送。
6. 工作資料、原始 PDF、自訂單價與接續列數只暫存在此頁面。重新整理或關閉此頁會清除，請先匯出需要的成果。舊版 JSON 備份可從「文件匯入」單獨載入。

### 廠商文件匯入與 Excel

- 系統從文字型 PDF 讀取文件抬頭、銷貨單或發票標題、單號、日期、金額及品項。逐頁檢查文件識別欄位，分開處理不同單據並記錄來源頁碼。同一頁混合兩種文件時會顯示解析失敗。
- 華茂以正規化發票號碼比對。拍檔以發票備註及出貨單上的出貨單號比對。拍檔發票缺出貨單號時，僅於訂單單號唯一且品項、金額一致時採用訂單單號。案件優先用同廠商的既有單號定位，其次用收件公司及可核對的電話或地址。華茂缺聯絡資料時，可用品名對應的 POS 採購金額（差額 5 元內）、完全相符的商家名稱及唯一候選定位。銷貨單有單號但未列發票時，只歸檔銷貨單，發票欄留空待補。
- 買賣方統編衝突、同單號有不同內容、候選案件不唯一時會保留未配對。同單號原件會保留。金額、明確的發票日期或品項有差異時，若單號及案件已確認，會保存附件關聯並標記提醒，金額與發票需核對後才納入請款。拍檔發票早於出貨或與出貨相隔逾七日也會提醒。
- 案件詳情可查看配對依據、來源頁碼及解析結果，也可替換文件或下載原始 PDF。移除案件附件只解除案件參考，原件暫存至本次操作結束。無文字層的掃描件請改用原始電子 PDF，或在案件內人工輸入。
- 發票的號碼與日期自動帶入。銷貨單欄位空白時，可用同案明確對應的發票回補。人工修正可在發票下方操作，系統保存修改前後欄位並更新後續匯出。設備、跨案分攤、金額及請款核對維持原有流程。相應 Excel 會在「廠商文件」與「廠商品項」補充頁列出已關聯文件。移除附件時已存發票仍由請款區個別管理。
- 「檔案直轉」保留華茂款項匯入、請款單轉換與舊有下單訊息操作。華茂款項匯入的單一 PDF 讀取失敗會記在處理紀錄，其餘有效銷貨單可照常匯出。「華茂對帳」保留獨立的比對及發票查詢。

### 產生內部系統報價單 PDF

1. 開啟案件，確認品項與數量。若有缺價或配對不明，在「逐項銷售單價」填寫並儲存。
2. 核對客戶名稱、報價單號、公司及報價日期，再依需要填入統編、報價窗口、聯絡方式、地址、期限與備註。
3. 按「產生 PDF 預覽」，核對後下載。價格依序使用本案已儲存的逐項單價、可唯一配對的 SAP 歷史單價或報價匯入值。僅有一種完整稅別時會列該稅別合計。兩種稅別金額都完整時，稅額依含稅與未稅合計差額列示。
4. 隨附字型支援可選取的繁中 PDF。檔案約 7 MB。如遇字型不支援的字元，畫面會標出字元以便更正。原始掃描或用印 PDF 可作為附件參考，報價內容以人工確認的資料為準。更新或關閉表單會清除當次預覽。

### 補件與例外

- 可補匯入新版 POS。同一工作表及來源列以最新資料為準。內容相同會略過，改名不影響比對，不同來源列保留為不同案件。該列若改屬另一公司或另一報價，舊附件與發票會與新案件分開保存。設備變更後請重新核對發票。
- 主控台右上「資料來源與範圍設定」可補匯入「內部系統報價單.xlsx」、「SAP資料庫」Excel，或在開啟案件後選擇供應商並匯入「請款單匯出.xlsx」。預覽可翻頁，跨頁勾選會在套用時一併納入。銷貨單與掃描報價可在案件詳情加入來源參考並人工補欄。
- Excel 欄位接受原生 XLSX 及相容的舊 XLS。選錯類型、缺少必要的資料欄位或工作表時，畫面會說明原因。廠商下單訊息與華茂查詢結果可翻頁，查詢匯出包含完整結果。
- 同案有多張發票時，逐張選擇對應設備。若為另一筆採購，請在即時庫存另建一個來源列。跨案共用發票請填各案分配金額，加總須與原票一致。
- SAP 主表的「vk請款單」優先取 POS「下單設備資料」的「設備請款單號」。有新舊差異時請查看「待確認」。
- 華茂的已關聯發票與銷貨單金額一致、單一憑證及品項數量可核對時，待核對的發票可先填入 SAP「請款憑證」與「憑證日期」。該發票涵蓋品項的「含稅採購單價 × 數量」全部核對一致，且合計等於發票含稅金額時，「請款總金額」只會填在第一筆對應設備。仍應核對標記的單據差異。
- SAP Key-in 準備表的拍檔「出貨廠商」為 VAA0001432，「出貨廠商ID」為拍檔科技。匯出使用可確認的歷史、報價或發票資料，再以固定單價補足。缺少一種稅別時以 5% 試算至小數第二位。實際發票金額仍計入「請款總金額」，同一發票只計一次。未確認價格會列入「待確認」。
- P8802、EPSON 及 M303 每台贈送兩捲紙，贈品以零元列示。已辨識的贈品會先扣抵贈送數量，單購以每捲含稅 NT$50 帶入。若只有一列紙捲且數量超過贈送額度，暫按數量含贈品拆列並列入「待確認」。若該列全部為付費加購，可將 POS 設備名稱標示為「發票紙捲（加購）」後重新匯入。
- 部署版已內建 12 項 SAP 固定單價，首次開站即可使用。當次從「SAP 固定單價」匯入的自訂價表優先於內建值，重新整理後使用部署版內建值。網站若公開，訪客可讀取內建價表。
- 僅單購發票紙捲、含稅商品小計在 NT$100,000 以內時，每筆訂單另列一筆運費，未稅 NT$143、含稅 NT$150。與設備混購、單購設備或已有運費紀錄時不另加。
- SAP 主表沿用 VK 的 A 至 AC 欄。用 Excel 左上名稱方塊輸入 `SAP_Copy_Range`，按 Enter 可選取全部資料列後一次複製。未取得的欄位留白，拍檔下單日期仍保留在備註後的 AD 欄。
- SAP 匯出按原 VK 欄序整理勾選案件，保留對應既有單號及歷史文字。產出為 Key-in 用資料副本，工作簿的其他分頁、原巨集及公式不會套用到新檔。若原設備數量或資料來源衝突，請核對「待確認」。

### 使用環境

Excel 操作可從本機打開此網頁。大量檔案可透過套件的本機 HTTP 啟動方式或已部署的 HTTPS 網站使用背景解析。直接開啟本機檔案時，解析在頁面執行，瀏覽器也可能限制 PDF 或剪貼簿功能。

### 調整表格

- 拖曳表格右下角可調整高度，寬度隨工作區變動。同一瀏覽器會保存高度。手機可點按控制點切換高度，左右滑動表格看其餘欄位。鍵盤可用上／下方向鍵微調，Home 恢復預設。

### 選單、色系與通知

- 左上按鈕可展開或收合選單。桌面收合後保留圖示，手機收合後隱藏選單。右上可切換淺色及深色，設定保存在目前瀏覽器。
- 右下通知依序顯示。一般通知約 5.5 秒後自動關閉，也可按「×」關閉。滑鼠停留或鍵盤焦點在通知內時會暫停倒數。錯誤通知需手動關閉。
- 「系統資訊」的「處理紀錄」保留本次開頁的匯入、配對、匯出及錯誤等紀錄，最新的顯示在上方。關閉或重新整理網頁會清空本次紀錄。

### 本機使用及 GitHub Pages 更新

- 解開發布 ZIP，保留原資料夾層級。本機可開啟 `index.html`。
- 發布時，在 GitHub 的 **Settings → Pages** 確認來源，將解壓後的全部檔案放到該發布資料夾，同次提交。若從 v15.17 更新，請移除舊的 Drive 同步檔案。v15.18 留在瀏覽器的案件及 PDF 不會載回；若需刪除舊副本，可從瀏覽器清除此網站的資料，介面偏好也會一併重設。保留 `index.html`、`.nojekyll`、`vendor/` 和 `docs/` 的相對位置。
- 等待 **Actions** 顯示部署成功，重新整理確認頁首為 **v15.23**。營運 Excel、報價及案件工作檔請留在公司內部。


### 系統資訊

左側「系統資訊」可查看處理紀錄、轉換規則及使用說明。三個分頁切換時會保留目前勾選的案件及處理紀錄。

### Gmail 備援

Gmail 預填網址包含 To、CC、主旨和內文，若內容敏感、連結過長、瀏覽器擋住新分頁或預填不完整，可用「複製主旨」、「複製內文」及「手動開啟 Gmail」。收件資訊可在 Gmail 撰寫畫面修改。部署管理人員可在 `site/app.js` 變更正式預設。
