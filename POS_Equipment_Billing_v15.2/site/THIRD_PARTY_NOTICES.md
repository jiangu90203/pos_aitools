# Third-party components

- SheetJS CE 0.20.3: Apache-2.0; `vendor/xlsx.LICENSE`. Obtained through the `@e965/xlsx` distribution mirror on jsDelivr because this environment receives HTTP 403 from the official SheetJS CDN. Package metadata is retained in `vendor/xlsx-package.json`. Runtime version was verified. It was not byte-compared to the official CDN artifact; this remains a provenance verification item.
- PDF.js 3.11.174: Apache-2.0; `vendor/pdfjs.LICENSE`. Core/worker obtained from jsDelivr's `pdfjs-dist` package; CMaps and standard fonts from the matching npm tarball. CMap/font directory license notices are preserved. `vendor/pdf-resources.js` is a base64 transport bundle of those assets generated by `tests/build_pdf_resources.py` for file:// operation without network font requests.
- Original icons, embedded mascot and styling are preserved from the supplied project; ownership/rights remain with their respective holders. This update does not grant new rights to those assets.

Exact component sources, versions, sizes and SHA-256 checksums are in `docs/DEPENDENCIES.json`. This is not a claim of comprehensive security certification.
